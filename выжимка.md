# Портфолио: Техническая документация

Данный материал подготовлен на основе моей выпускной квалификационной работы на тему «[Тема диплома]». Ниже представлена переработанная выжимка ключевых тезисов в формате технической документации.

## 1. Аналитическая записка (по материалам Введения)

Источник: ВКР, раздел «Введение».

### Проблема
- Отсутствие автоматического контроля в помещении
- Высокая нагрузка на оператора видеонаблюдения
- Энергозатраты при постоянном освещении

### Решение
- Установка датчиков движения (PIR)
- Интеграция с IoT и беспроводными протоколами (ZigBee, Z-Wave, LoRaWAN)

### Преимущества
1. Снижение числа ложных срабатываний — запись видео только при движении
2. Экономия электроэнергии — свет включается по событию
3. Гибкость монтажа — беспроводное подключение

## 2. Глоссарий

| Термин | Определение |
| :--- | :--- |
| PIR-датчик | Датчик, реагирующий на тепло тела человека |
| Ложное срабатывание | Тревога, вызванная не угрозой, а помехой (животное, сквозняк) |
| IoT | Подключение устройств к интернету для обмена данными |
| ZigBee / Z-Wave | Протоколы беспроводной связи для умного дома |
| LoRaWAN | Технология дальней беспроводной передачи данных |
